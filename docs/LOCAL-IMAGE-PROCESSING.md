# 本机去背景与高清放大

适用于本机开发画布及已接通 GPU／ComfyUI 的网站隔离发布版。所有任务都由对应后端连接的 ComfyUI 执行，不使用浏览器去背景模型，也不调用付费图像接口。正式 API 校验登录会话、同源来源与账户级任务归属，未登录返回 401。

## 使用

- 选中图片，点击工具栏“去背景”：自动提交背景移除工作流，保留原图并在旁边输出同尺寸透明 PNG。
- 点击“高清放大”：选择 2× 或 4×，通过 SeedVR2 v2.5.1 生成新图片节点。AI 会重建细节，可能改变文字、面部或纹理。
- 两类任务共用本机队列，同一时间只提交一个未完成的画布图片处理任务。支持取消、失败重试及刷新恢复。
- ComfyUI 未运行时，提交任务会尝试启动已配置的本机环境；缺少节点或模型会明确报错，不降级成浏览器插值。
- 发布网站不会自动访问每位访客电脑里的本机 ComfyUI；管理员必须先在 GPU 服务设置中配置服务器可达的 GPU/ComfyUI，并准备 Python/Pillow。GPU 不在线或模型/节点缺失时会显示检查状态，不伪称任务已处理。
- 不再设置原先的 2048px／8192px／3200 万像素限制；不会静默改变输入尺寸。实际处理仍受内存、显存及 ComfyUI 资源限制。

## 工作流

- 去背景：LoadImage → easy imageRemBg（RMBG-1.4，透明输出）→ SaveImage。
- 高清放大：LoadImage → GetImageSize → ComfyMathExpression（原图短边 × 2 或 4）→ SeedVR2VideoUpscaler → SaveImage。DiT 使用 3B FP8，VAE 使用 FP16 分块编码／解码。没有固定 2048 短边或二次插值放大。
- 去背景结果以模型输出的透明通道为准，与输入已有透明通道相乘；颜色取自原图，避免重复预乘造成暗边。高清放大在服务端缩放并合成原始透明通道，严格校验最终尺寸。
- 去背景及历史任务继续连接 127.0.0.1:8188；新放大任务固定连接 127.0.0.1:8190 的独立 SeedVR2 服务，共用 D:/other/comfyui/ComfyUI-aki-v1.7/ComfyUI-aki-v1.7 环境与模型文件。不关闭既有进程，不改动用户正在编辑的工作流。
- 任务记录保存引擎、倍率及固定种子 42；重启后按记录恢复到原服务。浏览器不能指定服务地址、模型或任意工作流。内部 mode=faithful 仅为兼容已保存的画布数据，不代表 SeedVR2 不会重绘细节。

## 自动保存

- localhost:3004 左侧文件夹按钮通过本机服务打开 Windows 系统目录选择器，不依赖内嵌浏览器的目录选择能力。取消会关闭提示并保留原目录；提示面板也可“稍后设置，返回画布”。
- 本机选择记录按浏览器身份存入当前用户 LocalAppData/共振画布/save-directories.json，刷新页面和重启 Vite 后恢复。普通图片、去背景和高清放大共用所选位置。本地目录接口限制回环访问、Host 和同源 POST，不接受浏览器指定磁盘路径。

- 新提交的去背景、高清放大任务成功后，由本地服务自动写入当前 Windows 用户主目录下的 Downloads/共振画布。
- 文件名为操作名称加唯一任务 ID，格式为 PNG。回传画布与保存到本机的是同一份文件。
- 本地服务保留上述目录中的备份；画布收到结果后，优先写入已选择且仍有权限的保存目录。未选择目录或写入失败时，自动触发浏览器 PNG 下载，使用浏览器设置的下载位置。
- 浏览器可能拦截自动下载，节点只提示“已触发浏览器下载”，不声称文件已落盘；可允许本站自动下载或点击节点下载按钮。文件夹写入成功才显示“已自动保存”。
- 浏览器按任务 ID 记录下载触发结果，防止重复轮询、刷新恢复时重复下载；清除站点存储会清除此记录。历史已完成节点不自动补下载，仍可手动下载。
- 任务记录保存下载路径。刷新页面、重复轮询与重启画布服务不会重复下载历史成功任务，不覆盖同名的不同内容文件。
- 下载目录不可写时，结果仍回传画布，节点显示自动保存失败提示；可使用原有下载按钮手动保存。
- 图片处理 API 对精确 Host 192.168.0.228:3004 开放远程访问；localhost/回环 Host 仍只接受本机连接。写请求必须来自对应的同源 HTTP 页面；跨站请求、伪造 Host、缺失浏览器身份均被拒绝，不提供任意地址 CORS。
- 任务身份由各浏览器独立持有，查询、取消和下载仍校验任务归属；其他用户不能操作别人的任务。共享 GPU 同时只处理一个画布任务，繁忙时请稍后重试，不会取消别人的任务。
- 远程用户无需安装 ComfyUI，生成结果返回发起者画布并自动触发其电脑的浏览器下载。服务电脑仍保留原有下载备份；浏览器限制自动下载时应允许本站下载或手动点击节点下载。
- 本次只开放图像处理接口，不开放服务电脑的桌面工程、系统文件夹选择、任意文件或命令执行。ComfyUI 8188／8190 端口仅监听 127.0.0.1，不直接暴露给局域网。

## 验证

- Node：node --test server/upscale-workflows.test.mjs server/image-processing.test.mjs
- Python：使用 ComfyUI 环境中的 python.exe 运行 server/upscale-image.test.py
- 构建：npm run build
- 2026-09-14 实机验收：288×384 输入去背景成功，PNG 为 RGBA 且透明通道包含 0 和 255；2×保真输出为 576×768。两类 API 回传文件与自动保存文件逐字节一致。
- 2026-09-17 SeedVR2 实机验收：321×479 透明 PNG 的 2× 输出 642×958、4× 输出 1284×1916；透明通道与原图按目标尺寸缩放的结果逐像素相同。经过真实服务上传、执行、回传、后处理及自动保存；耗时约 7.2 秒／10.2 秒，仅代表该样图。隔离验证脚本见 workflows/seedvr2-2.5.1/verify-canvas.mjs。
