# 同事电脑的本机工程保存（Windows / macOS）

## 同事如何使用

1. 登录局域网画布后，点击“新建工程”或“设置本机保存”，按电脑芯片下载对应启动器。
2. Windows x64：下载 ZIP，完整解压后打开 Resonantor-Desktop 文件夹，双击“启动画布.vbs”。
3. Mac Apple 芯片（M1/M2/M3/M4 等）：下载 resonantor-desktop-mac-arm64.tar.gz，解压后双击“启动画布.command”。
4. Mac Intel：下载 resonantor-desktop-mac-x64.tar.gz，解压后双击“启动画布.command”。
5. 在自动打开的 http://127.0.0.1:3006/ 页面登录原有账号，创建或导入工程；电脑重启后再次双击对应启动器。重复双击会复用正在运行的服务，不启动多个实例。

无需管理员权限，不需要另装 Node、Python、ComfyUI 或模型。运行进程只监听本机回环地址，不向同事的局域网开放端口。若公司禁用了 VBS 或 macOS Gatekeeper 阻止首次打开，请联系管理员审核下载包；不要绕过系统安全策略。Mac 可在 Finder 中右键“启动画布.command”并选择“打开”后确认；如果解压工具丢失了可执行权限，可在该文件夹终端执行 chmod +x 启动画布.command runtime/node。

## 双击 HTML（Mac / Windows）

- 如果 Mac 的启动器仍被系统策略拦截，可下载“下载双击 HTML（Mac / Windows）”，保存后直接双击 `resonantor-canvas-double-click.html`。
- 该文件已内置画布前端资源，不需要解压、Node、Python 或 macOS `.command` 权限；可离线创建、打开、重命名、删除本地工程，并通过导入 / 导出 `.js` 文件迁移工程。
- 工程数据保存在当前浏览器的 IndexedDB 中，不会自动保存到桌面。请使用画布的导出功能定期保存 `.js` 备份；清除浏览器的网站数据会清除该浏览器中的双击版工程。
- 双击 HTML 不能启动 ComfyUI、本机代理或后台服务；需要登录、云端模型、高清放大、去背景、自动写入桌面等功能时，请使用 Windows / Mac 启动器或局域网页版本。

## 文件在哪里

- 工程在当前 Windows 用户的实际桌面（支持 OneDrive 或桌面重定向）下：“共智体画布工程 / 账户-身份摘要 / 工程 UUID”。
- 每个工程有 project.json 索引及 snapshot-*.js 快照。默认 5 分钟自动保存、最多 5 份；可在画布 Auto save 调整、立即保存。
- 同一电脑不同账号的工程目录隔离；不同电脑使用各自桌面，工程不会自动跨电脑同步。
- 最近项目、打开、导入、重命名、删除及保留数量复用现有工程管理逻辑。删除移入该账户目录的“已删除工程”，不是永久删除。
- 不要清理工程目录中的文件。删除启动器文件夹不会主动删除桌面工程。
- 普通图片的下载目录与工程目录独立。启动器页面是本机安全上下文，可通过浏览器授权选择本机图片文件夹。

## 联网与权限

- 登录及模型请求仍发送至固定服务器 http://192.168.0.228:3004；高清放大和去背景仍在服务器 GPU 上执行。
- 新建、打开、保存、列出工程由本机服务处理，不转发工程内容到服务器。服务器原有桌面接口仍禁止远程访问，不能通过放开该接口让网页写进同事电脑。
- 生成模型所需的输入内容和图片仍会按原功能上传处理；“工程保存在本机”不表示生成请求完全离线。
- 工程 API 每次检查服务器登录状态，并按服务器确认的用户 ID 隔离。服务器断网或登录失效时暂时无法保存新的桌面快照，画布会报错；现有文件不会删除。请恢复连接后立即保存，或手动导出当前工程。
- 浏览器端的临时草稿不是多账号安全边界。共享电脑请使用各自 Windows 账户或独立浏览器配置，不共用已登录的浏览器。
- 浏览器不能指定任意上游地址、磁盘路径或执行命令。代理仅允许固定模型和登录接口，不开放服务器目录选择、后台管理或任意文件访问。
- 此版启动器不支持管理员后台页和完整微信网页 OAuth 跳转；使用用户名、密码注册/登录即可。后台仍由管理员在服务器管理页面使用。

## 故障与更新

- 打不开本机页面：检查解压是否完整及本机 3006 端口占用，查看启动器文件夹中的 start.log。
- 无法登录或生成：确认服务器在线且可访问 192.168.0.228:3004。
- 当前支持 Windows x64、Mac Apple 芯片（arm64）和 Mac Intel（x64）；手机不支持本机桌面保存启动器。
- 双击 HTML 适用于 Mac 与 Windows 的现代桌面浏览器；该版本不替代需要本机服务的桌面保存启动器。
- 启动器包含前端静态版本，服务器界面升级后须下载新的 ZIP；关闭旧的启动器 Node 进程后运行新版，桌面工程不受影响。不自动终止系统中其他 Node 进程。
- 管理员打包命令：npm run build:desktop-companion（Windows x64）、npm run build:desktop-companion:mac:arm64（Mac Apple 芯片）、npm run build:desktop-companion:mac:x64（Mac Intel）、npm run build:single-html（双击 HTML）。输出位于 desktop-companion-dist。
- 打包使用独立的无环境文件配置，只包含静态前端、必要的工程模块与 Node 运行时；不复制 .env、模型密钥、账号库、桌面工程或用户上传文件。
