# 节点自动对齐

- 拖动单个节点时，对其他画布节点的左边缘、水平中心、右边缘及上边缘、垂直中心、下边缘进行对齐；也支持相邻边缘贴齐。
- 吸附范围为屏幕上的 8 像素，随画布缩放换算，不改变鼠标拖动手感。X、Y 轴独立计算，可同时吸附。
- 对齐时显示青色虚线，连接拖动节点与参考节点；松手、远离吸附范围或拖拽中断后隐藏。
- 按住 Alt 拖动可临时关闭吸附。多选拖动和整组拖动保留原行为，不改变选中节点之间的相对位置。
- 仅点击节点不会触发吸附；列表专用节点不参与对齐。松手使用相同吸附计算，最终坐标继续复用项目自动保存逻辑。

验证：运行 npm run test:server 中的 node-alignment.test.mjs；独立浏览器验证 X/Y 拖动、虚线、释放、Alt 和 50% 缩放。
