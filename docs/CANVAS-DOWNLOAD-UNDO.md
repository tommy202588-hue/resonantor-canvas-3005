## 图片下载原因与修复

正式 API 的模型生成按管理员配置的提供商域名放行，但下载接口使用另一份固定白名单。配置中的模型成功返回白名单外的 CDN 图片地址后，网页可以显示图片，却无法通过下载代理读取图片字节：代理返回 `403 target_not_allowed`，前端随后打开保存失败窗口。本地回归已复现同一链路；未调用线上计费模型或读取用户私有图片来复现。

- 成功的托管图片模型响应中的 HTTPS 结果链接由服务器按账户、完整 URL 登记，最多保留 24 小时，总数有上限。OpenAI JSON、Gemini Markdown 和 SSE 均可识别。
- 下载代理只为对应账户生成的完整链接增加临时授权，不全局放开任意域名。每次下载及重定向仍校验 HTTPS、无内嵌凭据、公共 DNS/IP、响应大小和图片 MIME；不向图片服务器发送模型密钥。
- 未授权链接、其他账户的临时链接、改动签名的链接和内网/环回地址仍被拒绝。管理员既有下载白名单仍可使用。服务重启或临时授权到期后，不在固定白名单内的旧链接需要源站允许浏览器直读，或者管理员配置可信下载域名；已获取的 Blob、已保存的工程图片和磁盘文件不受此限制。
- 前端使用官网子路径和登录凭证请求代理。代理不可用时，仅尝试无凭证读取支持 CORS 的源图片；保留具体失败原因，不下载 HTML 错误页充当图片。
- 手动图片下载复用同一读取逻辑并优先使用已有 Blob。真实失败仍有提示和补存入口；不靠隐藏窗口冒充修复，不重试付费生成。
- 浏览器下载是否允许、最终目录和系统权限仍由用户控制。已授权文件夹优先写入；权限失效时回退浏览器下载，不后台弹权限窗口。

## 撤销原因与修复

旧版本只在删除、复制等少数动作前保存整张画布，新建、拖动、参数等操作没有记录；整图回滚还会覆盖无关的后台生成结果。

- 使用按字段的历史记录，覆盖新建、粘贴、上传、删除、拖动、缩放、连接、分组、排列、标题/提示词/内容/参数修改等操作，最多保留最近 20 步。
- 一次拖动或缩放计一步；选择、初始化、无变化操作不占历史。
- Ctrl+Z / Command+Z 仅撤销相关变更，不覆盖无关生成结果。撤销不撤回已发生的模型计费。
- 输入框和 contenteditable 使用原生文本撤销；参数回滚同步更新面板，工程切换清空历史。
