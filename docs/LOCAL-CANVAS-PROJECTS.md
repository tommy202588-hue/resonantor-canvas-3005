# 共智体首页与本地工程

## 使用

- 只有注册并登录后才能使用画布。新建、打开、导入和恢复工程会先校验会话，未登录则弹出登录窗口；管理后台入口与管理员方式见 ADMIN-ACCESS.md。

- 打开 localhost:3004 默认进入首页。左上角为“共智体”，主标题为“Do something amazing.”；最近项目以圆角预览卡片展示。
- 点击“新建工程”输入名称，创建空白画布；可导入既有 JSON 工程或本功能生成的 JS 工程快照。之前未归档的浏览器画布会保留为独立恢复草稿。
- 画布左上角“← 共智体”先保存当前工程，再返回首页。切换工程前保存，存在进行中的生成任务时阻止切换，避免把结果写进其他工程。
- 普通图片下载目录与工程目录相互独立，原有去背景、高清放大、节点吸附功能不变。

## 桌面文件

- 其他局域网电脑如需把工程写到自己的桌面，请使用首页“设置本机保存”提供的 Windows x64、Mac Apple 芯片或 Mac Intel 启动器。Windows 完整解压后运行“启动画布.vbs”；Mac 解压 .tar.gz 后运行“启动画布.command”，在自动打开的本机页面登录原账号。工程保存在各自桌面的“共智体画布工程 / 账户目录”，默认 5 分钟保存、保留 5 份；模型继续调用原服务器。不通过开放服务器桌面接口来实现客户端保存。详见 DESKTOP-COMPANION.md。

- 运行服务的同一台电脑也可通过自身网卡 IP（例如 http://192.168.0.228:3004/）访问工程；服务器同时校验连接来源为本机地址、Host 为本机地址且端口正确、写入 Origin 同源。不会开放其他局域网电脑读写桌面，不信任转发地址头。
- HTTP IP 页面使用安全随机数生成兼容的 UUID v4，不再要求 crypto.randomUUID 可用。不同地址的浏览器草稿和配置仍各自独立，桌面工程列表共享；原有 ComfyUI 与系统下载目录接口的访问限制不变。

- 通过 Windows 系统桌面目录定位，包括被重定向到其他磁盘或 OneDrive 的桌面；在其下创建“共智体画布工程”。本机实际解析为 D:/共智体画布工程。
- 每个工程使用独立 UUID 子目录，包含 project.json 索引与 snapshot-时间戳-UUID.js 文件。名称相同的工程不会覆盖彼此。
- JS 文件内容为 export default 后的纯 JSON 数据；导入只做 JSON 解析，绝不执行 JavaScript。仍兼容手动导出的 JSON 文件。
- 快照复用现有图片 Blob 序列化逻辑，保存图片、多图、节点尺寸和位置、连线、分组及视口。JS 工程导入不会改动当前全局 API 设置。
- 可直接用首页“导入工程”选择任意保留的 JS 快照，作为一个新工程恢复。不要手动修改 project.json 索引。

## Auto save

- 创建工程立即写入第一份快照，之后默认每 5 分钟保存一次，新工程默认最多保留 5 份。已有工程的保存数量不自动重置，避免覆盖用户原有设置。
- 右上角 Auto save 可设置频率 1–120 分钟、最大保存数 1–100；设置按工程保存，重启后仍有效。也可立即保存。
- 保存数量包括创建、定时、立即保存及返回首页时的快照；降低上限会立即清理此工程最旧的受管理快照，始终保留最新文件。其他工程及用户额外放入的文件不受影响。
- 页面关闭或电脑休眠时不能继续运行定时器；页面恢复可见时会检查是否需要补保存。浏览器临时草稿另行保存，用于恢复尚未到达桌面保存周期的编辑。
- 保存失败显示错误，不伪装为成功。新快照写入后才清理旧版本；同时打开同一工程的多个页面时检测版本冲突，不静默覆盖其他页面的新内容。

## 验证

- npm run test:server 覆盖 JS 数据解析、默认频率、定时器防并发、版本数量、旧文件保护、索引损坏、同名工程、并发版本冲突与本机 API 边界。
- 实机验证：通过首页创建工程、实际桌面 JS 文件、PNG 图片嵌入及透明通道、最近项目重新打开、JS 文件导入、修改频率为 1 分钟及最大 2 份、刷新后设置恢复。
- 定时验证记录真实的 300000 / 60000 毫秒周期，并直接触发定时回调检查保存结果，不预先等待完整五分钟。
- 项目构建通过。全量 TypeScript 检查仍有仓库原有的 displayError、apiRequestMode 等诊断，未在本功能中修改无关代码。

## 首页视觉与工程管理

- 首页 Logo 使用用户提供的“微信图片_20260817141747_509_2.png”，等比例缩小并以圆角显示。流动渐变标题与半透明卡片组成毛玻璃界面。
- 背景为本地生成的 12 秒无声 H.264 循环视频（768×432，约 370 KB），不请求外部视频服务。CSS 负责虚化；页面隐藏、离开首页或系统偏好减少动态效果时暂停播放，视频加载失败使用本地海报图。
- 素材位于 public/brand；scripts/build-home-assets.py 可用 NumPy、Pillow、imageio-ffmpeg 重新生成。视频为程序化抽象色彩动画，不包含第三方素材。
- 点击工程卡片名称旁的编辑图标可重命名。工程 ID、文件目录、历史备份不变，新名称同步显示在 Auto save，并写入后续快照。
- 点击卡片右上角选择框，再点击“删除选中工程”。确认后将该工程完整移动到根目录下的“已删除工程”，而不是永久擦除；其中的 JS 备份仍可通过“导入工程”恢复。取消不会修改任何文件。
- 删除当前工程会同时停止该工程的自动保存并清理其浏览器草稿，防止任务再次保存或刷新后恢复已删除工程。正在生成的工程须先结束或取消任务。
- Auto save 与提示词按钮处于同一个横向布局，保持 12px 间距；窄窗口中整体移到第二行，保存面板保持在视口内。
- 回归包含重命名后的备份名称、版本冲突、删除确认、非选中工程保护、移动后的文件完整性，以及已删除工程不能被过期自动保存重新创建。
