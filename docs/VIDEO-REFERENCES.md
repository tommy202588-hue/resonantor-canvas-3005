# 视频节点上游参考图

将图片节点连接到视频节点后，选中视频节点，提示词窗口上方会显示「上游参考图」，与图片节点使用相同的缩略图和 @ 引用组件。

- 点击缩略图，或在提示词输入 @，可选择图1、图2等；候选支持图片标题搜索和方向键、Enter / Tab 选择。
- 视频提示词存在 @图N 时，仅提交引用到的可用上游图片；重复引用不会重复提交，同批图片保持上游连接顺序。
- 未使用 @图N 时保留原行为：提交全部可用上游参考图。角色 @ 引用不会被当成图片引用。
- 合并上游文本节点内容后统一处理图片引用。发送时将上游图号映射到实际提交的图片序号，例如只选 @图2，提交第二张图片并将提示词里的引用转换为「参考图1」。画布提示词仍保留 @图2 标签。
- 空图片节点不占用图号，界面显示与请求使用同一编号规则。引用不存在的图片会在调用模型前报错，不会静默使用其他图片。
- 参考图数量、首尾帧或多图用途仍由既有视频提供商适配器决定，本次不改变各模型能力限制。

验证：Node 测试覆盖默认全部、精确选择、多位图号、重复引用、失效引用、上游文本合并。隔离浏览器验证视频缩略图窗口、点击插入、输入 @ 与键盘选择、只引用图2时的实际模型请求、未引用时全部传入和失效引用不调用模型。测试不使用真实模型额度，不修改用户工程。
