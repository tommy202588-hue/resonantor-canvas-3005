# 共振画布原生桌面版

桌面安装包通过 Electron 启动本机回环服务，浏览器页面和本机文件保存接口不暴露到局域网。用户双击 Windows `.exe` 或 macOS `.app` 后，界面仍使用统一的服务器登录、模型和 GPU 任务接口，但工程文件会保存在该用户自己的桌面目录。

## 用户侧行为

- 工程目录：`桌面/共智体画布工程/<账户哈希>/`。
- 图像下载：保留用户已选择的本机保存目录；未选择时由浏览器或桌面端保存设置处理。
- 登录和云端模型：桌面端将认证、模型生成、高清放大和去背景请求代理到统一服务器，密钥不会打包到客户端。
- 服务器地址：默认 `http://192.168.0.228:3004`。部署桌面包时可设置 `RESONANTOR_SERVER_URL` 为固定的画布服务器根地址。

## GPU 服务切换

管理员登录服务器后访问 `/admin/gpu`，可管理并立即切换当前 GPU 服务。

- `本机托管`：只能使用服务器本机的回环 ComfyUI 地址，可由后端一键启动。
- `局域网 GPU`：只能填写私有 IPv4 地址；后端仅连接已经启动的远程 ComfyUI，绝不会从浏览器或后端执行远程命令。
- 已提交任务会绑定提交时的 GPU 服务。切换不会迁移、取消或中断运行中的其他任务；后续新任务使用新服务。

## 发布说明

- Windows：运行 `npm run build:desktop` 或 `npm run build:desktop:portable` 生成可直接双击的安装包。
- macOS：必须在对应架构的 Mac 上运行 `npm run build:desktop:mac:arm64` 或 `npm run build:desktop:mac:x64`。M 系列发布包还需要配置 Apple 签名和公证环境变量，避免 Gatekeeper 阻止用户打开应用。
