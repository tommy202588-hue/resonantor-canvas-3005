- 用户上线后截图报告 `Refused to connect to data:image/jpeg;base64,...`。真实官网浏览器复现 JPEG/PNG Base64 和 Blob 图片 `fetch` 全部受到 `connect-src` 拦截；此前测试只覆盖远程 URL，且 `pageerror` 不包含该安全策略事件。
- 当前版本：`20261009T081308Z`；前一版本：`20261009T073355Z`。归档 SHA256：`be3d31203a03933a3f30db941254555478158496c3c3817ca51b75c639a4b9fc`。
- 只在画布 `connect-src` 增加 `data:` / `blob:`，不开放任意脚本、`unsafe-eval` 或新的远程主机。页面显示图片与通过 fetch 读取图片属于不同 CSP 指令，不能仅配置 `img-src`。
- 本次采用 `csp-only` 发布模式，逐项验证后端源码和前端资源与前一版本一致，平滑重载 Nginx；画布 API PID 始终为 `1126563`，保留正在执行的任务、登录会话和内存中的生成图片授权。
