# 画布登录与管理后台

## 访问入口

- 画布首页：http://localhost:3004/ 或 http://192.168.0.228:3004/。
- 管理后台：http://localhost:3004/admin；局域网地址为 http://192.168.0.228:3004/admin。
- 后台与画布由当前 Vite 3004 服务同时提供，无需另开端口。只有管理员账号能读取后台数据；普通注册用户访问管理接口会收到 403。

## 管理员登录

本机已通过 scripts/setup-local-admin.mjs 初始化管理员。用户名为 admin，随机强密码仅写入：

C:/Users/Administrator/AppData/Local/Resonantor/auth/admin-access.json

用文本编辑器打开此文件，取 username 与 password，在 /admin 页面登录。该文件包含管理员密码，应仅由服务电脑的管理员保管；不要放到网站目录、分享或提交 Git。后台页面不显示密码或微信 AppSecret。

重复运行 node scripts/setup-local-admin.mjs 不会重置已有管理员、密码或普通用户。新安装可通过 CANVAS_ADMIN_USER 与 CANVAS_ADMIN_PASSWORD 配置初始管理员；已有账号不会被环境变量静默覆盖。账号数据损坏时也不会自动覆盖。

## 普通用户访问规则

- 首页右上角提供“登录 / 注册”，弹窗内点击“注册新账号”可直接使用用户名和密码注册，无需微信配置。用户名为 3–32 位字母、数字、下划线或短横线，以字母或数字开头；密码为 12–128 个字符。
- POST /api/auth/register 创建普通用户，公开用户 ID 等于注册用户名。用户名先到先得，忽略首尾空格且不区分大小写判重；重复注册返回 409 并提示修改用户名。密码仅存储为加盐哈希，注册后自动登录，首页右上角显示用户名。接口校验来源、请求大小及注册频率，不能通过注册参数获取管理员权限。后台用户列表同样使用用户名作为用户 ID。
- 既有账号无需迁移：数据库内部 UUID、会话归属与工程关联保持不变，仅对外账号信息中的 ID 使用用户名。
- 未登录用户可以浏览首页，但新建、打开、导入、恢复工程时会自动出现登录窗口；登录成功后继续刚才的操作。
- 最近工程需要登录后从服务端读取；同一页面已显示的工程卡片再次点击时也会重新验证会话。
- 微信首次授权后自动注册并产生用户 ID；再次登录复用 ID。真实微信扫码仍需要配置网站应用凭据，详见 WECHAT-ACCOUNTS.md。
- 登录失效或退出后，画布回到首页，工程自动保存与图像任务轮询暂停；原节点和浏览器草稿不会被直接清空。
- 后端统一拦截所有 /api/ 业务请求，未登录直接返回 401，不能靠绕过前端使用工程、高清放大、去背景、生成代理或本地目录服务。
- 账号登录接口保持公开；后台 /api/admin/overview 在登录基础上额外验证 admin 角色。
- 登录不会解除原有 Host、Origin、任务归属及桌面文件访问限制。该本地版本沿用服务电脑现有桌面工程库，不等同于多租户云端工程隔离。

## 后台目前提供

### MiniMax 默认音频

默认音频提供商为 MiniMax 语音合成，模型为 speech-2.8-hd，接口为 https://api.minimax.cn/v1/t2a_v2，类型为 minimax。使用非流式 hex 输出，默认音色 male-qn-qingse，MP3、32000 Hz、128 kbps、单声道。密钥仅存于后台私有配置，不写入源码或本说明。

画布将 MiniMax 十六进制音频转换为可播放、可随工程保存的数据 URL。输入文本需少于 10000 字符；错误码 1004 提示鉴权失败，1008 提示余额不足，失败不会伪装成音频结果，也不会自动改用其他付费模型。

2026-09-15 实机验证：默认配置读取正常且前端不接收实际密钥；短语音请求返回 1008（余额不足），需账户补充余额后才能完成真实合成。代码与模拟测试通过。

- 统一模型设置：在 /admin 点击“模型设置”，或直接访问 http://localhost:3004/admin/models（局域网地址 http://192.168.0.228:3004/admin/models）。
- 管理员可为图片、视频、文本、音频设置提供商名称、接口类型、HTTPS 地址、API 密钥、模型列表、默认提供商和画布批量并发数。模型列表每行填写“模型 ID | 显示名称”；也可只填模型 ID。
- 首次使用可点击“导入此浏览器旧配置”，或“导入设置 JSON”，检查后点击“保存统一配置”。此操作仅管理员可用，不会自动导入工程文件内的模型设置。尚未配置时，画布会提示联系管理员，不使用浏览器旧密钥兜底。
- 配置保存至账号目录下的 model-settings.json。管理员和用户读取接口都不返回实际 API 密钥；留空保留原密钥，修改服务地址或类型时需要重新填写密钥。请像保护管理员凭据一样保护此文件。
- 画布不再显示模型设置入口，所有登录用户从服务端获取可用模型；后台保存后，刷新画布、切回窗口或等待最多约 30 秒同步。用户仍可选择后台已开放的模型及生成参数。
- 生成请求由 /api/model-request 注入服务端密钥并转发，只允许已配置提供商的生成和任务查询接口；旧的客户端自带密钥生成代理默认禁用。ComfyUI 高清放大、去背景继续使用现有工作流。
- 模型回归测试使用模拟上游，不消耗真实模型额度。真实生成需管理员填写有效的提供商信息，并保证服务电脑能连接对应 HTTPS 服务。

- 已注册用户列表：用户 ID、显示名称、账号类型和创建时间。
- 微信扫码注册是否已配置。
- 服务端会话密钥是否已配置；不显示密钥明文。
- 管理员登录、退出、刷新列表。此版本不提供用户删除、权限修改或密钥在线编辑。

## HTTP 与 HTTPS

当前 3004 是局域网 HTTP 服务。为兼容该地址的登录，本地 Vite 默认不设置 Secure Cookie，但仍设置 HttpOnly、SameSite=Lax，并校验会话签名与来源。HTTP 不能加密账号密码和会话流量，只应在可信网络使用；正式多人部署请使用 HTTPS 并设置 CANVAS_COOKIE_SECURE=true。独立 API 服务保持 Secure Cookie 默认开启。

不要将管理员密码用于其他网站。微信回调地址仍必须使用配置正确的 HTTPS 域名。

## 文件保存与验证

用户、会话、服务端密钥与管理员访问文件位于 %LOCALAPPDATA%/Resonantor/auth，可通过 CANVAS_AUTH_DATA_DIR 配置本地目录。针对 Windows 加密目录的 EXDEV 替换问题，使用固定命令的原生文件移动作为兼容回退，并验证源和目标在同一目录；不接受网页传入文件路径或命令。

运行 npm run test:server 与 npm run build；canvas-access.test.mjs 验证匿名业务请求拦截、登录/退出、会话过期、普通用户后台拒绝、敏感字段不泄露、管理员初始化幂等及加密目录写入。
