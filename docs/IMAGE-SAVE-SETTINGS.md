# 图片自动保存

- 生成图片、去背景和高清放大共用保存策略：有已授权目录时写入该目录，否则发起浏览器下载。文件夹权限失效或写入失败时回退下载，图片仍保留在画布中。
- 无目录不再中断保存或强制弹窗。批量图片逐张保存，一张失败不阻止其他图片保存。
- 左侧文件夹按钮打开图片保存设置。本机服务、桌面应用及支持目录 API 的安全浏览器环境可选择文件夹；取消不改变原目录。
- 局域网 HTTP 不支持网页目录选择，设置面板提供浏览器下载指引，不再显示无效的“选择保存文件夹”按钮。
- Edge / Chrome：右上角菜单 → 设置 → 下载 → 位置 → 更改。需要自动保存时关闭“下载前询问保存位置”，并允许本站自动下载多个文件。该设置影响浏览器的其他下载。
- 网页无法读取浏览器设置的下载路径，也无法确认浏览器是否最终写入磁盘，所以下载状态仅显示“已发起下载”，不声称保存成功。
- 选择“使用浏览器下载”会记住偏好（仅保存可序列化记录）；刷新后继续使用。已生成的旧图片可点击节点下载按钮补存。
- 远程浏览器不会调用本机原生目录选择服务，也不会写入服务器用户的目录。远程网页内固定目录写入需要可信 HTTPS 与兼容浏览器。

验证：node --test server/processed-image-browser.test.mjs server/local-save-directory.test.mjs
