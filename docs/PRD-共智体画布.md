## 2. 产品概述

### 2.1 产品愿景

让用户在一个可视化、可复用、可保存的无限画布中完成从剧本、分镜、角色资产到图像、视频、音频和项目交付的完整创作流程。用户通过节点和连线组织创作逻辑，模型由后台统一管理，工程文件默认掌握在用户自己的电脑中。

### 2.2 要解决的问题

1. 剧本、提示词、参考图和生成结果分散在多个工具中，创作上下文容易丢失。
2. 图像、视频、文本和音频模型的调用方式不一致，普通用户难以管理 API、模型和任务状态。
3. AI 生成存在异步、失败、超时和计费风险，用户需要可信的任务状态、失败重试和结果保留机制。
4. 工程数据和媒体资产不能只依赖浏览器缓存或服务器，用户需要可迁移、可备份的本地工程文件。
5. 本机 GPU、ComfyUI 和云端模型需要在不暴露任意命令、任意地址和服务器文件系统的前提下协同工作。

### 2.3 产品价值

- **统一创作上下文**：节点、连线、参考图、提示词、分镜和生成历史在同一画布内可追溯。
- **降低模型使用门槛**：用户不在画布中填写密钥，管理员统一配置模型与供应商。
- **本地优先保存**：工程可写入当前用户授权的桌面目录，便于备份和迁移。
- **可控的本机 GPU**：通过后端固定配置连接 ComfyUI，不把 GPU 地址或任意命令暴露给浏览器。
- **明确的失败边界**：失败不覆盖原图、不伪造进度、不自动切换到未知付费服务。

## 3. 产品目标与非目标

### 3.1 本阶段目标

| 目标 | 成功标准 |
| --- | --- |
| 完成节点式多模态创作 | 用户可以在同一工程中组织文本、图片、视频、音频和脚本节点 |
| 支持从剧本到分镜 | 上传或粘贴剧本后，可生成、校对、编辑和回传分镜结果 |
| 支持可控图片处理 | 去背景和 SeedVR2 2×/4× 高清放大均由配置的 ComfyUI 执行 |
| 支持本地工程生命周期 | 新建、打开、导入、重命名、删除、自动保存、恢复和导出均可完成 |
| 支持多用户和后台管理 | 用户注册登录；管理员统一配置模型、GPU 服务和账号系统 |
| 保持 3004 稳定版本 | 3005 的改动、发布和实验不覆盖或重启 3004 |

### 3.2 非目标

- 不在本阶段实现完整的在线协同编辑、多人同时编辑同一工程和实时评论。
- 不向浏览器开放 ComfyUI 端口、远程桌面、任意服务器文件读写或任意命令执行。
- 不在画布中保存或回显真实 API Key、微信 AppSecret、管理员密码或会话密钥。
- 不把单机 JSON 存储包装成高可用、多实例、跨地域云端数据库。
- 不在双击 HTML 版本中承诺登录、云端模型、本机 GPU、去背景、高清放大或桌面自动保存。
- 不自动把用户请求切换到付费 API、其他模型或其他 GPU 服务。

## 4. 用户与使用场景

### 4.1 用户角色

| 角色 | 主要诉求 | 权限边界 |
| --- | --- | --- |
| 普通创作者 | 创建工程、组织节点、生成和下载内容 | 只能访问自己的工程和自己发起的任务 |
| 导演/编剧 | 导入剧本、整理分镜、关联角色与场景参考 | 使用脚本工作台和分镜导出 |
| 视觉设计师 | 维护参考图、生成图片、去背景、高清放大 | 使用图片节点和本机 GPU 处理能力 |
| 项目管理员 | 统一维护模型、供应商、GPU 和账号状态 | 访问 `/admin`、`/admin/models`、`/admin/gpu` |
| 部署维护者 | 维护 3004、3005、Nginx、ComfyUI 和隧道 | 通过服务器和本机运维权限操作，不通过前端下发命令 |

### 4.2 核心场景

1. **新用户创作**：访问首页 → 注册/登录 → 创建工程 → 授权本机工程文件夹 → 添加节点 → 生成并保存。
2. **剧本转分镜**：上传 TXT/SRT/Markdown/Fountain → 校对镜头 → 管理角色、场景和道具 → 合成镜头提示词 → 回传文本或视频节点。
3. **参考图驱动视频**：图片节点连接视频节点 → 在视频提示词区域查看上游图片 → 使用 `@图N` 精确选择参考图 → 发起视频任务。
4. **GPU 图片处理**：图片节点点击“去背景”或“高清放大” → 后端提交固定 ComfyUI 工作流 → 轮询任务 → 结果作为新节点返回并触发下载。
5. **工程迁移**：导出 `.json/.js` → 在另一台电脑导入 → 重新授权本机文件夹 → 继续编辑和自动保存。

## 6. 视觉与交互原则

### 6.1 视觉语言

- 品牌名称统一为 `RESONANTOR | 共智体`。
- 首页采用循环视频背景、虚化处理和玻璃质感层；不改变既有品牌背景素材的整体氛围。
- 首页主标题 `Do something amazing.` 使用 Cylburn 视觉风格；品牌和界面辅助文字使用 Orator Std 或系统回退字体。
- 卡片、弹窗、按钮和节点使用圆角、半透明、细边框和弱阴影，保持深色创作工作台风格。
- 重要状态使用明确的颜色和文字，不只依赖颜色：排队、处理中、成功、失败、取消均必须可读。

### 6.2 交互原则

1. 用户操作可撤销；撤销应恢复上一次画布状态，不把生成任务误当成普通编辑操作。
2. 异步任务状态必须来自后端或真实请求阶段；不得用计时器伪造百分比。
3. 任何会产生费用或覆盖数据的操作都要在提交前说明范围和风险。
4. 原图和原节点默认保留，处理结果创建为新节点，不把原图置为失败。
5. 任何文件夹、桌面或系统权限都必须由用户主动点击授权，网页不可静默访问任意路径。
6. 关闭面板不等于取消任务；需要区分“关闭界面”和“取消任务”。

## 7. 功能需求

### 7.1 首页、登录与注册

**优先级：P0；当前状态：已实现，微信能力依赖配置。**

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| AUTH-01 | 未登录用户可浏览首页 | 首页正常展示，不读取需要登录的工程内容 |
| AUTH-02 | 首页右上角提供登录和注册入口 | 点击后弹出统一账户面板，不离开当前上下文 |
| AUTH-03 | 用户名注册先到先得 | 用户名忽略首尾空格且不区分大小写判重；重复时返回明确提示 |
| AUTH-04 | 用户 ID 使用注册用户名 | 注册成功后首页和后台列表显示用户名；内部仍使用不可猜测的 UUID 关联数据 |
| AUTH-05 | 登录后才能使用工程和图像处理 | 未登录点击新建、打开、导入、恢复或处理功能时自动弹出登录面板 |
| AUTH-06 | 支持微信扫码注册/登录 | 微信凭据、AppSecret 和 token 只在服务端保存；未配置时显示待配置状态 |
| AUTH-07 | 会话安全 | 使用 HttpOnly、SameSite Cookie；退出、过期、篡改会话均回到未登录状态 |

### 7.2 首页与最近项目

**优先级：P0；当前状态：已实现。**

- 首页左上角展示 `RESONANTOR | 共智体` 圆角品牌标识。
- 首页中心展示主标题和最近项目区域。
- 最近项目使用圆角矩形卡片，展示项目名称、最近保存时间和打开入口。
- 项目支持重命名；重命名结果同步到工程索引和 Auto save 设置中的工程名称。
- 项目支持删除。删除默认从最近项目隐藏并移动到当前账号的已删除区域，不直接擦除有效快照。
- 用户没有工程时展示新建工程引导，不显示其他账号工程。

### 7.3 工程、本地保存与自动保存

**优先级：P0；当前状态：已实现；网页固定目录依赖 HTTPS/localhost 与浏览器能力。**

#### 工程操作

- 新建、打开、导入、重命名、删除、导出和恢复工程。
- 支持导入工程 JSON/JS；导入 JS 只解析受控工程数据，不执行任意 JavaScript。
- 导入失败必须保留当前画布和原工程，不清空当前内容。
- 工程保存失败时保留浏览器临时草稿，并提供“重新授权后恢复”入口。

#### 保存位置

- 本机桌面默认根目录为“共智体画布工程”。
- 工程目录结构：`共智体画布工程/账户摘要/工程 UUID/`。
- 工程索引为 `project.json`；快照为 `snapshot-时间戳-UUID.js`。
- 浏览器目录授权由用户主动选择；取消授权不改变现有目录配置。
- 局域网 HTTP 或不支持 File System Access API 时，降级为浏览器下载或本地启动器服务，不伪称已写入固定目录。

#### Auto save

- 默认每 5 分钟自动保存。
- 默认每个工程最多保留 5 份快照。
- 可设置保存间隔 1–120 分钟、最大快照数 1–100 份。
- 自动保存成功后才更新有效快照索引；新快照失败不得删除旧快照。
- 页面刷新、重启服务和重新打开项目后恢复最近有效快照。
- 不同账号的工程目录、浏览器草稿和工程列表相互隔离。

### 7.4 无限画布与节点系统

**优先级：P0；当前状态：已实现。**

#### 通用能力

- 无限画布平移、缩放、小地图、节点选择、框选、复制、删除和分组。
- 节点可拖动、调整大小、折叠和重命名。
- 节点通过连线传递文本、图片、视频、音频和资产引用。
- 节点状态统一为 idle、loading、success、error、cancelled 等可展示状态。
- 单节点失败不把上游节点或原始媒体置为失败。

#### 自动对齐吸附

- 拖动节点时，对齐左边缘、水平中心、右边缘、上边缘、垂直中心和下边缘。
- X/Y 轴独立吸附，吸附时显示青色虚线。
- 吸附范围为屏幕约 8 像素并随画布缩放换算。
- 按住 Alt 临时关闭吸附；多选和整组拖动保持相对位置。

#### 撤销与重做

- Ctrl/Cmd+Z 恢复上一次画布编辑操作，而不是跳过或回滚到更早的无关状态。
- 历史记录覆盖节点、连线、分组、位置、尺寸、文本和视口等可编辑状态。
- 生成任务请求、下载和后台配置不作为普通画布编辑历史写入。
- 撤销/重做不删除已成功生成且已被项目引用的媒体 Blob。

### 7.5 文本节点与提示词系统

**优先级：P0；当前状态：已实现。**

- 支持创建、编辑、复制、删除文本节点。
- 文本节点可作为图片、视频、音频和脚本节点的上游输入。
- 支持提示词预设、历史记录、复制最终提示词和查看原始提示词/最终发送提示词。
- 提示词中的 `@图N` 用于选择上游图片；不存在的引用在调用模型前报错。
- 节点中显示当前模型、尺寸、比例、数量、任务状态和错误信息。

### 7.6 图片节点与图片生成

**优先级：P0；当前状态：已实现；模型与 API 依赖后台配置。**

- 支持文生图、图生图和多参考图生成。
- 图片节点显示上游参考图缩略图，支持点击选择或输入 `@图N`。
- 未使用 `@图N` 时默认提交全部可用上游图片；重复引用不重复提交。
- 生成成功后创建或更新结果节点，记录模型、提示词、参考图关联和生成时间。
- 生成图片按用户保存设置自动保存或触发浏览器下载；单节点和批量节点均可下载。
- 下载失败不丢失画布结果，节点显示失败原因并提供手动下载。

### 7.7 视频节点与视频参考

**优先级：P0；当前状态：已实现；供应商能力依赖后台配置。**

- 图片节点连接到视频节点后，视频节点上方显示与图片节点一致的上游参考图窗口。
- 点击缩略图、输入 `@图N`、方向键和 Enter/Tab 均可选择参考图。
- 参考图编号只统计有效图片节点，空图片节点不占用编号。
- 视频节点合并上游文本内容，并将画布中的 `@图N` 映射为实际提交的参考图序号。
- 上游视频可用于 Remix；首尾帧、多图用途和数量限制由供应商适配器决定。
- 视频任务必须显示提交、排队、处理中、成功和失败状态；退出生成界面后任务继续在当前页面执行。
- 剧本生成器只创建待生成视频节点，不自动批量调用付费视频 API。

### 7.8 音频节点

**优先级：P1；当前状态：已实现，默认 MiniMax 配置依赖余额和密钥。**

- 音频节点使用提示词或文本内容生成语音/音频。
- 默认音频供应商可配置为 MiniMax 语音合成，模型、音色、格式和采样参数由后台统一管理。
- 服务端保存密钥，浏览器只接收可播放结果，不接收真实密钥。
- 余额不足、鉴权失败、模型错误必须显示真实错误，不伪装成成功音频。
- 音频 Blob 可随工程保存、重新加载、下载和删除。

### 7.9 脚本生成器与分镜工作台

**优先级：P1；当前状态：已实现；AI 生成依赖后台文本模型。**

#### 输入与限制

- 支持 TXT、MD、SRT、Fountain 文件或粘贴原稿。
- 支持 UTF-8、带 BOM 的 UTF-16 和 GB18030。
- 单文件最大 512 KB，正文最多 40,000 字符；超限明确提示，不静默截断。
- 目标镜头数为 1–40。

#### 三步工作台

1. **确认镜头**：生成并编辑镜头表，字段包括时长、画面、景别、光影、对白、音效、运镜和资产关联。
2. **准备资产**：维护角色、场景和道具的文字设定与参考图；支持上传或按需生成资产。
3. **合成提示词**：将镜头、资产设定和全局风格合成为图片/视频提示词；每批最多处理 5 个镜头。

#### 任务与回传

- 关闭编辑界面、按 Escape 或点击“返回画布等待”不会取消任务。
- 节点显示可信阶段百分比：0% 校验、25% 等待模型、50% 模型返回、75% 结果校验、100% 写回节点。
- 非流式模型等待期间保持阶段值，不使用计时器虚增进度。
- 成功结果可发送到文本节点或视频节点；关联参考图作为共享图片节点连接。
- 页面刷新或关闭后不自动重试已提交任务，保留原稿和已有分镜，避免重复费用。

### 7.10 去背景与高清放大

**优先级：P0；当前状态：已实现，并已接通 3005 远程 GPU 测试服务。**

#### 用户入口

- 选中图片节点，在节点上方工具栏展示带图标和文字的“高清放大”入口。
- 图片处理面板仅保留“去背景”和“保真放大”相关能力；旧版重绘增强不再作为产品选项。
- 提交前显示原始尺寸和预计输出尺寸；不静默缩小输入。

#### 去背景

- 固定工作流：`LoadImage → easy imageRemBg（RMBG-1.4）→ SaveImage`。
- 输出同尺寸 RGBA PNG，保留原图节点并创建新结果节点。
- 输出 Alpha 与原始透明通道合成，避免透明背景变黑、变白或出现暗边。

#### 高清放大

- 固定使用 SeedVR2 v2.5.1 工作流，支持 2× 和 4×。
- 2×/4× 通过 SeedVR2 目标分辨率生成，不使用浏览器插值冒充 AI 放大。
- 记录处理引擎、倍率和固定种子 42，结果保存来源信息便于复现。
- 输出 PNG 尺寸必须严格等于输入宽高乘以倍率；服务端对最终尺寸做校验。
- 当前不设置原先的 2048px、8192px 或 3200 万像素前端限制，实际资源边界由 GPU、显存、Pillow、ComfyUI 和请求体限制共同决定。

#### 任务与失败

- 去背景和高清放大共用画布图片处理队列，同时只允许一个未完成任务。
- 状态包括准备图片、提交任务、排队中、处理中、成功、失败、取消和等待连接恢复。
- 支持取消、失败重试、刷新后恢复查询；取消只操作当前账号拥有的任务。
- 服务未启动、节点/模型缺失、上传失败、显存不足、Pillow 不可用和 ComfyUI 执行失败必须分别提示。
- 远程 GPU 由管理员在后台配置；浏览器不能传入任意 ComfyUI 地址、模型名、文件路径或工作流。

#### 自动下载

- 有有效的本机保存目录时，生成图片、去背景和高清放大共用该目录。
- 没有目录或目录写入失败时，触发浏览器 PNG 下载，结果仍保留在画布。
- 自动下载状态只显示真实的“已写入”或“已触发下载”，不声称已确认浏览器落盘。

### 7.11 工作流库、生成历史和导入导出

**优先级：P1；当前状态：已实现。**

- 工作流库支持保存、导入、导出和从模板创建节点布局。
- 生成历史保存提示词、模型、参考图、时间、状态和结果关联。
- 工程导出为 JSON/JS；敏感的提供商密钥必须脱敏或完全排除。
- 导入工程只写入经过校验的节点、连线、分组、媒体和视口数据。
- 导入失败保留原工程，不覆盖当前画布。

### 7.12 管理后台

**优先级：P0；当前状态：已实现。**

#### 模型设置

- 管理员在 `/admin/models` 配置图片、视频、文本、音频四类供应商。
- 每个供应商包含名称、类型、HTTPS Base URL、API Key、端点模式、模型列表和默认模型。
- 支持模型列表拉取、手动添加模型 ID/显示名和批量并发设置。
- 保存使用服务端统一配置，密钥不回显；留空表示保留已有密钥。
- 普通用户不能读取管理接口或真实密钥。

#### GPU 服务设置

- 管理员在 `/admin/gpu` 登记本机或远程 GPU 服务。
- 每个服务包含服务 ID、显示名称、类型、ComfyUI 地址、SeedVR2 地址和本机安装路径（仅本机托管）。
- 新任务使用当前激活服务；正在运行的任务继续绑定原服务，不被迁移。
- 远程 GPU 只允许可信内网地址或固定 SSH 回环隧道端口，禁止浏览器指定任意地址。
- 后台显示 ComfyUI、SeedVR2、模型、节点和 Python/Pillow 的实际就绪状态。

## 9. 安全、权限与合规要求

### 9.1 必须满足

- 所有业务 API 默认要求登录；管理员接口额外校验 admin 角色。
- 登录、注册、管理、任务和工程接口校验 Host、Origin、请求方法和请求大小。
- API Key、管理员密码、微信 AppSecret、session.key 和用户数据库不进入前端 bundle、工程导出或公开日志。
- ComfyUI 仅监听回环地址；远程 GPU 通过受限 SSH 回环端口连接，不公开 8188/8190。
- 浏览器不能上传任意工作流、指定任意模型、执行任意命令或选择任意服务器路径。
- 任务查询、取消和结果下载必须校验任务所属账号。
- 工程导入只解析 JSON 数据，禁止执行导入文件中的脚本。
- 文件写入采用临时文件、校验、原子替换和有效索引提交，失败不得破坏旧数据。

### 9.2 隐私边界

- 工程默认保存在用户选择的本机目录；云端仅保存登录、必要的工程索引或服务端任务状态。
- 生成请求中的提示词和媒体会发送到配置的模型供应商或 GPU 服务，界面应在相关功能处说明这一点。
- 双击 HTML 版本的数据仅在当前浏览器 IndexedDB 中，清理浏览器数据会丢失未导出的工程。
- 共享电脑应使用独立的操作系统账号或浏览器配置，不能把浏览器草稿当作加密隔离。

## 10. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 可靠性 | 任务失败不覆盖原节点；保存失败保留旧快照；服务重启不清空其他队列 |
| 可恢复性 | 刷新可恢复登录、工程、任务轮询和有效快照；无法续接的任务标记中断，不自动重试 |
| 性能 | 画布交互在常规节点数量下保持流畅；任务轮询每秒级更新，不阻塞编辑 |
| 可观测性 | 服务端记录请求 ID、状态码、耗时、任务阶段和错误码，不记录密钥和密码 |
| 兼容性 | 桌面 Chrome/Edge 为主要支持浏览器；固定目录写入要求安全上下文 |
| 可用性 | 失败状态必须同时提供文字说明和下一步动作；关键操作支持键盘 Escape、Enter、Ctrl/Cmd+Z |
| 可迁移性 | 工程可通过 JSON/JS 导出导入；媒体随工程或按项目策略打包 |
| 可维护性 | 3004 稳定线与 3005 隔离线独立发布；release 可校验、回滚，不覆盖账号和工程数据 |
| 国际化准备 | 当前中文为主，品牌和首页保留英文标题；后续抽离界面文案资源 |

## 12. 发布与运维策略

### 12.1 环境隔离

- 3004：稳定版本，不在本轮 PRD 对应发布流程中修改或重启。
- 3005：隔离测试/发布版本，使用独立 release、服务、数据目录、会话 Cookie 和后台配置。
- 正式网站测试入口使用 HTTPS 子路径；Nginx 只增加精确 location，不覆盖主站和旧接口。
- ComfyUI 和 GPU 隧道不公开到公网，任务由服务端固定地址访问。

### 12.2 发布流程

1. 执行服务测试、Python 测试、前端构建和发布包校验。
2. 生成带时间戳的 release 和 SHA-256 清单。
3. 上传到隔离 release 目录，校验清单后切换 `current` 链接。
4. 仅重启 3005 测试服务；检查 healthz、登录、模型后台、GPU 后台和真实任务。
5. 验收通过后记录 release、校验值、配置变更和回滚点。
6. 失败时把 3005 `current` 切回上一个 release，不删除用户账号、工程和任务记录。

### 12.3 GPU 切换

- 切换前检查 ComfyUI、SeedVR2、节点、模型和 Python/Pillow。
- 允许多 GPU 配置并选择一个激活服务。
- 已开始任务绑定提交时的 GPU，不被切换迁移。
- GPU 离线时，新任务明确失败或等待连接恢复，不清空 ComfyUI 队列。

## 14. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 云模型 API 余额、限流或 502 | 生成失败、用户无法判断原因 | 显示供应商错误映射；后台支持切换模型；不自动切换付费服务 |
| GPU 显存不足 | 高清放大失败或耗时增加 | 真实错误提示、限制并发、支持取消和重试、记录显存环境 |
| ComfyUI 节点/模型版本不一致 | 工作流提交失败 | 启动前检查节点和模型；固定工作流版本；后台显示缺失项 |
| 浏览器文件夹权限失效 | 自动保存失败 | 保留旧快照和临时草稿；引导重新授权；降级浏览器下载 |
| 远程 SSH 隧道断开 | 网站图像处理不可用 | runtime 状态检查、明确提示、管理员重连隧道，不开放公网端口 |
| 单实例 JSON 并发写入 | 工程或账号数据冲突 | 文件锁、修订号、原子写入；多实例部署前迁移数据库 |
| 用户误以为任务可后台永久执行 | 刷新后任务无法续接 | 明确提示页面生命周期；后续可引入持久化任务队列 |
| 共享电脑浏览器被复用 | 草稿和会话泄露 | 使用独立系统账号/浏览器配置；不把浏览器草稿当作安全隔离 |

## 16. 当前版本结论

截至 2026-09-28，共智体画布已经具备从首页登录、工程管理、无限画布、节点式多模态生成、脚本分镜、视频参考图、统一模型后台到本机/远程 GPU 图像处理的完整产品骨架。3005 隔离版本已用于发布验证，ComfyUI 与 SeedVR2 图像处理链路已完成真实任务验收；3004 继续作为不受影响的稳定版本。

本 PRD 的下一步不是继续扩大功能边界，而是围绕以下事项完成产品化收口：模型供应商配置与错误体验、不同 GPU 的任务调度、真实用户跨浏览器工程迁移、微信正式联调、4×/大图回归和在线协作架构决策。
